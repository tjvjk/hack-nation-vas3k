# The Negotiator pitch deck

Slidev deck for the HackNation / ElevenLabs pitch. The deck follows the meeting guidance: hook first, a single problem–solution sentence, a live demo as the center of the pitch, one high-level technical diagram, and a clear impact close.

## Run with Bun

```bash
cd presentation
bun run dev
```

Build the static deck:

```bash
bun run build
```

The `export` script is available once a compatible Playwright browser is installed. It is not required to present the deck in the browser.

## Pitch runbook

1. Open the deck, intake, campaign, carrier console, and final report in separate tabs.
2. Keep the three short call moments ready: market-benchmark concession, documented decline, and verified-quote concession.
3. Record a three-minute backup video before submission and keep it available locally.
4. Submit at least one hour before the deadline, after checking the selected challenge.
