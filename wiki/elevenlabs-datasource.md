# ElevenLabs The Negotiator: анализ источников данных

Источник требований: `tracks/pdf/1784382172163-01-ElevenLabs-The-Negotiator.docx.pdf`, раздел **Data Sources and Hints**, страница 5.

## Краткий вывод

В задании рекомендуются две разные категории данных:

1. **Источники контрагентов** — чтобы программно получить список компаний и телефонов для обзвона.
2. **Ценовые бенчмарки** — чтобы сравнивать полученные предложения, выявлять подозрительно низкие цены и выбирать переговорные рычаги.

Голосовой агент не обязан самостоятельно искать компании во время разговора. Практический поток выглядит так:

1. backend находит компании через Places/Yelp/OSM/FMCSA;
2. формирует и фильтрует список телефонов;
3. голосовой агент звонит выбранным контрагентам;
4. сохраняет детализированные предложения в общей структуре;
5. сравнивает предложения с рыночными ориентирами;
6. проводит повторные переговоры и формирует итоговый рейтинг.

## 1. Источники компаний для обзвона

### Google Places API

- **Ссылка:** [Google Places Text Search API](https://developers.google.com/maps/documentation/places/web-service/text-search)
- **Данные:** название, категория, адрес, координаты, телефон, часы работы, рейтинг, количество отзывов, сайт.
- **Плюсы:** высокая полнота локальных компаний; удобный поиск по категории и географии.
- **Ограничения:** нужен API-ключ и включённый биллинг; телефон, рейтинг и часы работы относятся к платным полям; действуют ограничения на хранение и повторное использование данных.
- **Применение:** основной источник списка компаний для быстрого MVP.

### Yelp Places API (Yelp Fusion)

- **Ссылка:** [Yelp Places API](https://docs.developer.yelp.com/docs/places-intro)
- **Данные:** компании, категории, телефоны, адреса, рейтинг, количество отзывов, ценовой уровень и часы работы.
- **Плюсы:** полезные рейтинги и отзывы; хороший дополнительный источник для проверки качества контрагентов.
- **Ограничения:** нужен API-ключ; выдача ограничена тарифом и возможностями endpoint; компании без отзывов могут отсутствовать.
- **Примечание:** в PDF используется название **Yelp Fusion**, тогда как актуальная документация называет продукт **Yelp Places API**, сохраняя endpoints `/v3`.

### OpenStreetMap

- **Ссылки:**
  - [Downloading OpenStreetMap data](https://wiki.openstreetmap.org/wiki/Downloading_data)
  - [Overpass QL](https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_QL)
  - [Региональные OSM extracts](https://wiki.openstreetmap.org/wiki/Extracts)
- **Данные:** POI, категории, адреса, координаты, `phone`, `contact:phone`, `website`, `opening_hours`.
- **Плюсы:** открытые данные; можно бесплатно выгружать выбранные категории через Overpass или скачивать региональные extracts.
- **Ограничения:** телефоны и часы работы заполнены неравномерно; данные требуют очистки и дедупликации.
- **Применение:** бесплатный базовый источник или дополнение к Google Places/Yelp.

### FMCSA для поиска перевозчиков

- **Ссылки:**
  - [FMCSA Company Census File](https://data.transportation.gov/Trucking-and-Motorcoaches/Company-Census-File/az4n-8mr2)
  - [FMCSA Motor Carrier Census Downloads](https://ai.fmcsa.dot.gov/SMS/Tools/Index.aspx)
  - [Search for a Registered Mover](https://www.fmcsa.dot.gov/protect-your-move/search-mover)
- **Данные:** USDOT, название компании, адрес, телефон, статус регистрации, тип деятельности, размер автопарка и другая регистрационная информация.
- **Плюсы:** официальный открытый источник; позволяет проверить легальность interstate mover и отсеять неподходящих перевозчиков.
- **Ограничения:** это реестр перевозчиков и safety/compliance-данные, а не база реальных цен на переезды.
- **Применение:** обязательная валидация перевозчиков и дополнительный источник контактов для moving-вертикали.

## 2. Ценовые бенчмарки по вертикалям

### Переезды: moveBuddha

- **Ссылки:**
  - [Moving Cost Calculator](https://www.movebuddha.com/moving-cost-calculator/)
  - [Moving Pricing Methodology](https://www.movebuddha.com/blog/moving-pricing-methodology/)
- **Данные:** ориентиры стоимости локальных и междугородних переездов с учётом расстояния, размера жилья, типа сервиса и рыночных условий.
- **Плюсы:** актуальные ценовые ориентиры; методология заявляет более 10 000 новых ценовых точек ежемесячно и ежемесячное обновление агрегатов.
- **Ограничения:** полная исходная ценовая база публично не выгружается; доступен калькулятор, агрегаты и публикации.
- **Применение:** baseline для red-flag rules и проверки предложений, но не замена реальным котировкам, полученным звонками.

### Медицина: FAIR Health

- **Ссылки:**
  - [FAIR Health Consumer Cost Lookup](https://www.fairhealthconsumer.org/)
  - [FAIR Health Data Repository](https://www.fairhealth.org/data)
  - [FAIR Health Benchmark Products](https://www.fairhealth.org/solutions)
- **Данные:** агрегированные billed charges и allowed amounts по медицинским кодам и географическим зонам.
- **Плюсы:** крупная база коммерческих и Medicare claims; бесплатный consumer lookup подходит для ручной проверки прототипа.
- **Ограничения:** полноценные benchmark datasets являются лицензируемыми коммерческими продуктами; условия сайта запрещают массовый scraping.
- **Применение:** референс для оценки медицинского счёта и подготовки аргументов для переговоров.

### Медицина: CMS Hospital Price Transparency

- **Ссылки:**
  - [CMS Hospital Price Transparency](https://www.cms.gov/priorities/key-initiatives/hospital-price-transparency)
  - [Официальные схемы и data dictionary](https://github.com/CMSgov/hospital-price-transparency)
- **Данные:** machine-readable files больниц с gross charges, discounted cash prices, payer-specific negotiated charges и другими стандартизированными полями.
- **Плюсы:** наиболее близкий к настоящему открытому ценовому датасету источник из списка PDF; есть официальные CSV/JSON-шаблоны и схемы.
- **Ограничения:** каждая больница публикует собственный файл; потребуется обнаружение URL, загрузка больших файлов, нормализация и контроль качества.
- **Применение:** основной открытый источник цен для medical-вертикали.

### Авторемонт: RepairPal

- **Ссылка:** [RepairPal Fair Price Estimator](https://repairpal.com/estimator)
- **Данные:** диапазоны стоимости ремонта по автомобилю, операции и ZIP-коду, включая ориентиры стоимости деталей и работ.
- **Плюсы:** удобный потребительский ценовой ориентир для распространённых ремонтных операций.
- **Ограничения:** публично представлен прежде всего веб-калькулятор; открытая bulk-выгрузка в задании не указана; для автоматизированного коммерческого использования нужно отдельно выяснять условия доступа.
- **Применение:** baseline для сравнения предложений автосервисов.

### Покупка автомобиля: Kelley Blue Book

- **Ссылки:**
  - [Kelley Blue Book Car Prices](https://www.kbb.com/car-prices/)
  - [KBB Vehicle Values for Business](https://b2b.kbb.com/kbb-vehicle-values/)
- **Данные:** Fair Purchase Price, Fair Market Range, trade-in и private-party values с учётом модели, комплектации, состояния и региона.
- **Плюсы:** узнаваемый рыночный ориентир, регулярно обновляемый на основе объявлений и транзакций.
- **Ограничения:** это не свободный bulk-датасет; B2B-интеграция и автоматическое получение valuations требуют коммерческого доступа и соблюдения правил отображения.
- **Применение:** аргумент для переговоров с дилерами или продавцами автомобилей.

### Грузоперевозки и аренда оборудования

PDF не называет конкретные датасеты, а рекомендует использовать **published rate cards** выбранной вертикали.

Возможный процесс:

1. выбрать конкретный сегмент и географию;
2. собрать официально опубликованные тарифы компаний;
3. сохранить дату действия, единицы тарификации, минимальный заказ, топливные и сервисные сборы;
4. нормализовать тарифы в общую схему;
5. использовать их как baseline, сохраняя реальные телефонные предложения отдельно.

Нельзя считать тарифы разных поставщиков сравнимыми без нормализации включённых услуг, ограничений и дополнительных сборов.

## 3. Собственный датасет переговоров

PDF отдельно рекомендует создавать **Golden calls & eval sets**. Это не внешний датасет, а набор эталонных звонков проекта.

Минимальная запись должна включать:

- идентификатор компании и источника контакта;
- подтверждённую спецификацию заказа;
- запись и транскрипт звонка;
- исходную цену;
- детализированные комиссии;
- финальную цену и условия после переговоров;
- использованный переговорный рычаг;
- найденные red flags;
- результат: quote, callback commitment или documented decline;
- оценки извлечения всех полей и соблюдения honesty constraints.

Такой набор нужен для проверки, что агент:

- извлекает каждую комиссию;
- не теряет важные условия;
- замечает предложение на 30% и более ниже рынка;
- не придумывает конкурирующие предложения;
- действительно изменяет цену или условия благодаря собранному рычагу.

## 4. Рекомендуемый набор для MVP по переездам

### Минимальная конфигурация

1. **FMCSA Company Census** — официальный список и проверка перевозчиков.
2. **Google Places API или OSM Overpass** — локальный поиск компаний и телефонов.
3. **moveBuddha** — предварительный ценовой диапазон.
4. **Собственные звонки** — реальные структурированные предложения и комиссии.
5. **Golden calls dataset** — тестирование извлечения данных, red flags и переговорной логики.

### Почему внешнего датасета недостаточно

Цель задания — не показать существующую среднюю цену, а получить сравнимые реальные предложения по телефону и изменить хотя бы одно предложение в ходе переговоров. Поэтому внешние данные служат только для:

- выбора компаний;
- проверки лицензии и репутации;
- оценки рыночного диапазона;
- выявления аномалий;
- подготовки честных переговорных аргументов.

Главным ценовым датасетом продукта в итоге становятся собственные структурированные результаты звонков.

| Источник | Тип | Открытый bulk download | API | Основная роль |
|---|---|---:|---:|---|
| Google Places | Коммерческий каталог | Нет | Да | Поиск компаний и телефонов |
| Yelp Places | Коммерческий каталог | Нет | Да | Поиск и проверка компаний |
| OpenStreetMap | Открытые геоданные | Да | Да, Overpass | Бесплатный поиск компаний |
| FMCSA Company Census | Государственный реестр | Да | Через data portal/downloads | Проверка и контакты перевозчиков |

| FAIR Health | Claims benchmarks | Только лицензируемые продукты | По договору | Медицинские бенчмарки |
| CMS hospital MRF | Государственно обязательные открытые файлы | Да, по больницам | Единого полного API нет | Реальные больничные цены |
| RepairPal | Проприетарный estimator | Нет | Публичный bulk API не заявлен | Бенчмарк ремонта |
| KBB | Проприетарные valuations | Нет | Коммерческий доступ | Бенчмарк стоимости авто |
